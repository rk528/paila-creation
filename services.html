Website design and development

A website is often the first place people learn what you do. It should make that clear quickly and make the next step obvious.

Where it helps

  • You need a website for a new business, organisation, or project.
  • Your current website is hard to update, hard to read on a phone, or no longer describes what you do.
  • People need a clear way to find your details and contact you.

How the work comes together

The work starts with what visitors need to find and what you want them to do. From there, the pages, content structure, and visual design are planned, then built to work across phones, tablets, and computers.

Web applications

A web application runs in the browser, but it does more than present information. It lets people enter, find, and act on data.

Where it helps

  • A process currently lives in spreadsheets, paper forms, or long message threads.
  • Several people need to see and update the same information.
  • You want a tool people can open from a browser without installing anything.

How the work comes together

A web application can bring a browser-based workflow into one place. The work involves mapping who does what, designing the screens for each task, and building the application so the information stays organised as it grows.

Android applications

An Android app puts a focused tool on the phone people already carry.

Where it helps

  • The people you serve are mostly on Android phones.
  • A task happens away from a desk — in the field, on the move, or at a counter.
  • You want a dedicated app rather than a website saved to the home screen.

How the work comes together

Designing for a small screen means deciding what matters most on each view. The work covers planning the app's screens and navigation, building it for Android devices, and testing it on the kinds of phones your users have.

Desktop applications

Some work is better suited to a program installed on a computer than to a browser tab.

Where it helps

  • People spend long stretches at a computer doing the same kind of task.
  • The software needs to be installed and run as its own program.
  • An existing desktop tool needs to be replaced or rethought.

How the work comes together

Desktop software is used for hours at a time, so layout, keyboard use, and clear forms matter. The work starts by understanding the daily routine the program supports, then designing and building around it.
